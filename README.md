# Ledgerly — финансовый кабинет и счета

Сводит счета, доходы и расходы в баланс и помесячный денежный поток.

**Проект:** Самостоятельная разработка.

## Что работает
- Создание и фильтрация счетов, смена статусов.
- Доходы и расходы с датой, категорией и описанием.
- Баланс, график за шесть месяцев, изменение доходов и настраиваемая цель.
- Импорт и экспорт CSV с проверкой данных и защитой от повторного добавления.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24.18.0 и pnpm 11.7.0.

```bash
npm install --global pnpm@11.7.0
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Расчёты выполняются в целых копейках; даты проверяются по календарю.
- Импорт CSV атомарный: ошибка не оставляет часть операций в базе.
- UUID операций и хеш импорта защищают от дублей; экспорт экранирует формулы таблиц.

## Проверка интерфейса

Playwright проверяет компьютерную и мобильную версии, отсутствие горизонтального прокручивания и повтор загрузки после ответа API 503. Ошибка отправки формы сохраняет введённые данные.

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```
