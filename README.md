# Ledgerly — финансовый кабинет и счета

Показывает сводку счетов и ожидаемые платежи.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Агрегаты сумм, список и фильтрация счетов.
- Создание счёта в интерфейсе, REST API статусов и удаления.
- SQLite и проверки входных данных.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Сводка рассчитывается по сохранённым счетам.
- Отрицательная сумма и неизвестный статус отклоняются API.

## Границы готовности
- График, финансовая цель, остаток, проценты роста и часть карточек — фиксированные иллюстративные значения.
- Банки, платежи, бухгалтерия, отчётность и выгрузки не подключены.
- Нет авторизации; это не система учёта реальных финансов.
