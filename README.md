# Ledgerly — финансовый кабинет и счета

Показывает сводку счетов и ожидаемые платежи.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Агрегаты сумм, список и фильтрация счетов.
- Создание счёта в интерфейсе, REST API статусов и удаления.
- SQLite и проверки входных данных.

## Стек
JavaScript, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24.18.0 и pnpm 11.7.0.

```bash
npm install --global pnpm@11.7.0
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Сводка рассчитывается по сохранённым счетам.
- Отрицательная сумма и неизвестный статус отклоняются API.

## Границы готовности
- График, финансовая цель, остаток, проценты роста и часть карточек — фиксированные иллюстративные значения.
- Банки, платежи, бухгалтерия, отчётность и выгрузки не подключены.
- Нет авторизации; это не система учёта реальных финансов.

## Проверка интерфейса

Playwright проверяет компьютерную и мобильную версии, отсутствие горизонтального прокручивания и повтор загрузки после ответа API 503. Ошибка отправки формы сохраняет введённые данные.

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```

## Проверка документации и обновлений

`python .github/scripts/check_docs.py` проверяет ссылки на файлы и изображения в Markdown, регистр имён и случайные локальные ссылки. Примеры команд внутри блоков кода не проверяются как ссылки. `--external` дополнительно проверяет публичные HTTP-ссылки: 404/410 считаются ошибками; авторизация, сетевые сбои и ограничения сервиса отмечаются как непроверенные. HTTP-проверка запускается еженедельно и вручную; локальные ссылки — при каждом push/PR. Фрагменты внутри страниц не проверяются.

Dependabot еженедельно предлагает сгруппированные обновления зависимостей и GitHub Actions. Автоматического слияния нет; обновления проходят CI. [История версии](CHANGELOG.md).
